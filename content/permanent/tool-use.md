Tool use is the mechanism by which an agentic system takes action in the real world. It involves the agent making structured calls to external tools based on a predefined schema.

**Why it matters**: Effective tool use is what transitions a language model from a passive chatbot to an active agent. The quality of tool descriptions is crucial for reliable tool selection.
