The CCAF (Claude Certified Architect - Foundations) Framework validates a practitioner's ability to design, implement, and operate production-grade AI systems using Claude, Claude Code, and the Model Context Protocol (MCP). It emphasizes practical, scenario-based knowledge for building robust, scalable, and reliable AI systems.

## Core Domains
- **Agentic Architecture & Orchestration**: Designing agent loops, multi-agent patterns, and session management.
- **Claude Code Configuration**: Utilizing `CLAUDE.md`, `.claude/` rule sets, and agent skills for terminal-native automation.
- **Prompt Engineering & Structured Output**: Using JSON schemas, few-shot prompting, and context pipelines.
- **Tool Design & MCP Integration**: Designing tools, handling errors in MCP, and leveraging transport types.
- **Context Management & Reliability**: Managing context windows, caching, compaction, and implementing robust retry/escalation strategies.
