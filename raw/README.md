# raw/

Đây là thư mục cho các nguồn gốc (raw sources). **KHÔNG BAO GIỜ chỉnh sửa file trong này** — chỉ AI đọc, không ghi.

## Cách dùng

### `articles/`

Web clips, saved articles. Dùng **Obsidian Web Clipper** để clip articles dưới dạng `.md`, rồi drop vào đây.

### `books/`

Book highlights, chapter notes. Export từ Kindle/Readwise hoặc gõ tay.

### `assets/`

Images được reference bởi raw sources.

## Sau khi drop file

Nói với AI agent: **"ingest `raw/articles/tên-file.md`"** — AI sẽ tự xử lý, tạo literature note, cập nhật permanent notes, và log.
